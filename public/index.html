更新について

GitHub Actionsが原則として日本時間の毎時23分（1日24回）にデータを取得し、サイトを再公開します。休日は前営業日の価格が表示され、ジョブ実行は遅れる場合があります。

02 /

価格の定義

投資信託は 1万口あたりの基準価額（分配金を含まない値）、金は米ドル建て金先物を円／gへ換算した参考価格です。店頭購入価格や現物スポット価格ではありません。

03 /

データ出典

株式・指数・金・為替はYahoo Finance系のデータ、投資信託は運用会社の公開基準価額資料等を利用します。利用条件は各提供元に従ってください。商用利用や再配信には別途許諾が必要になる場合があります。
