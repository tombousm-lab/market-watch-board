更新について

GitHub Actionsが原則として日本時間の毎時23分（1日24回）にデータを取得し、サイトを再公開します。休日は前営業日の価格が表示され、ジョブ実行は遅れる場合があります。

02 /

価格と評価額の定義

投資信託は 1万口あたりの基準価額（分配金を含まない値）、金は米ドル建て金先物を円／gへ換算した参考価格です。店頭購入価格や現物スポット価格ではありません。米国株は最新取得為替で円換算し、投資信託の数量は口数で入力します。

03 /

データ出典

株式・指数・金・為替はYahoo Finance系のデータ、投資信託は運用会社の公開基準価額資料等を利用します。利用条件は各提供元に従ってください。商用利用や再配信には別途許諾が必要になる場合があります。

ON-DEMAND REFRESH / GitHub Actions

最新データを手動取得

このボタンはGitHub Actionsの価格取得プログラムをその場で起動します。公開データが更新されるまで通常は数分かかります。取引所が休みの場合、価格そのものは変わりません。

初回のみ：GitHubの限定トークンを用意
  1. GitHubでFine-grained tokenを作成 ↗
  2. Resource owner：tombousm-lab／Repository access：Only select repositories → market-watch-board
  3. Repository permissions：Actions → Read and write。短い有効期限を設定し、発行したトークンを下へ入力してください。

トークンはこのページを開いている間だけ一時的に保持し、GitHub以外へ送信・GitHubリポジトリ・localStorageに保存しません。ページ再読み込みで消去されます。ChatGPTには貼り付けないでください。

トークンを使いたくない場合：GitHubのActions画面で「Run workflow」を実行 ↗ （GitHubログインが必要）
